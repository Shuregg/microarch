- Разработать конфигурируемый ассоциативный массив, параметризуемый по следующим параметрам: SETS, WAYS, DATA_WIDTH. 
- Массив должен уметь конфигурироваться в "краевые" случай — fully associative и direct-mapped.
- Данные, тэги, а также флаги валидности должны храниться в однопортовой памяти с синхронным чтением. Памяти мы разбиваем на 3 сегмента: tag, data, status.
- На данный момент ассоциативный массив будет read-only, то есть для тестов необходимо предусмотреть его инициализацию с помощью readmemh.
- Подготовить тестбенчи, демонстрирующие корректное поведение ассоциативного массива (hit по данным, которые в нём хранятся, и не hit по данным, которых нет) для конфигураций fully associative, direct-mapped и 4 way associative.
